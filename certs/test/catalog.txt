crit-cert.pem:
  Simple self-signed certificate with critical Basic Constraints and Key Usage
  extensions.
dh512.pem, dh512.der:
  512-bit DH parameters. Used for testing the rejection of lower-bit sized DH
  keys.
dh1024.pem, dh1024.der:
  1024-bit DH parameters. Used for testing the rejection of lower-bit sized DH
  keys.
digsigku.pem:
  ECC certificate with a KeyUsage extension without the digitalSignature bit
  set.
cert-ext-joi.pem:
  Simple certificate that includes OIDs for JurisdictionOfIncorporation
cert-ext-oid-collide.der:
  Non-critical extension whose 4-byte OID has the same wc_oid_sum() as
  prime256v1, so it maps to a NID with a longer canonical OID. Tests that
  wolfSSL_X509_set_ext() sizes the ASN1_OBJECT buffer from the certificate's
  OID, not the mapped one. Does not collide under WOLFSSL_OLD_OID_SUM.
  Signature is invalid; only ever parsed, never verified. Regenerate with
  certs/test/gen-oid-collide-cert.sh.
cert-events/*.der, cert-events/*.pem:
  Copies of certs/server-cert.der, each with exactly one defect and signed
  again with certs/ca-key.pem, so verification reaches the defect.
  good.der has no defect. strict-*.der and crl-this-update-future.der test
  the strict profile checks; strict-good.der passes them. The chain-*.pem
  files are chains for a server using certs/server-key.pem, with CAs keyed by
  certs/intermediate/ca-int*-key.pem under certs/ca-cert.pem; chain-good.pem
  has no fault. Used by the certificate validation event tests in
  tests/api/test_certman.c. Valid until 2049. Regenerate with
  certs/test/gen-cert-events.py.
